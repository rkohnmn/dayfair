# Changelog

## 1.0.1 — 2026-10-26

- Added Open Graph and X social card metadata, accessible image description, and free WebApplication structured data.
- GitHub Pages workflow now stamps canonical and absolute preview URLs using Pages metadata; supports repo subpaths and custom domains without placeholders.
- Added automated tests for the static site build and metadata.


## 1.0.0 — 2026-10-26

Initial public-ready GitHub Pages repository: local-first multi-bill calculation, inclusive occupancy and absence days, configurable fixed-fee allocation, integer-cent reconciliation, per-member balances and net settlements, responsive dark/light design, sample household, live updates, JSON backups, CSV/text/print exports, README, researched market rationale, docs, automated tests and Pages workflow.

### Known caveats

The static output was unit-tested and tested in constrained, inlined Chromium UI smoke mode. Live hosted navigation, screen reader testing and cross-browser QA require post-publication checks. See `docs/QA.md`.
